# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.1.3] - 2026-11-23

First PyPI release since 0.1.1: the 0.1.2 tag made a GitHub release, but its
PyPI upload failed, so 0.1.3 carries 0.1.2's changes to PyPI.

### Changed
- CI and release workflows use current versions of the GitHub actions.

## [0.1.2] - 2026-10-13 (GitHub only, not on PyPI)

### Added
- Community files: contributing guide, code of conduct, security policy,
  issue and pull-request templates, `CITATION.cff`.
- Dependabot configuration, release workflow with GitHub Releases, coverage
  reporting and strict `mypy` type checking in CI.
- Project URLs, keywords and minimum dependency versions in package metadata.

### Changed
- License metadata now uses the SPDX expression `MIT`.

### Removed
- Obsolete Travis CI configuration.
