## [0.1.2] - 2026-10-13

### Added
- Community files: contributing guide, code of conduct, security policy,
  issue and pull-request templates, `CITATION.cff`.
- Dependabot configuration, release workflow with GitHub Releases, coverage
  reporting and strict `mypy` type checking in CI.
- Project URLs, keywords and minimum dependency versions in package metadata.

### Changed
- License metadata now uses the SPDX expression `MIT`.

### Removed
- Obsolete Travis CI configuration.
